**INSTALLATION**
- Pour installer, éxécuter le script setup.py
- Pour lancer, lancer RIKAgroq pour utiliser l'assistant

**CAPACITÉS**
- Obtenir la localisation
- Avoir l'heure, date, etc.
- Avoir la météo de votre localisation
- Capture automatique de l'écran et analyse (à votre demande)
- Capture automatique de la webcam et analyse (à votre demande)
- Ouvrir une application installé sur l'ordinateur
- Ouvrir un lien web
- Recherche sur le web
- Envoyer un courriel
- Lire des courriels
- Éxécuter des actions custom via des protocols (protocols.json)
- Sauvegarder un fichier
- Reconnaitre une musique
- Jouer de la musique sur spotify

**OPTIONS**
- Certains paramètres peuvent être modifié dans `settings.json`
- Modifier l'overlay hi-tech en modifiant les assets
- Pour lui parler, appeler son nom (Rika par défaut) pour une conversation orale ou faire le raccourcis clavier dans les paramètres pour une conversation écrite (par défaut ctrl+alt+r)
- pour désactiver Rika, simplement lui dire au revoir ou lui demander de se mettre en veille
- _NOTE:_ L'input au clavier ne fonctionnera pas dans d'autres applications si le mode conversation est activé

*TROUBLESHOOTING*
- M'envoyer les fichiers log.log et debug.json en me mentionnant l'erreur. Vous pouvez aussi envoyer conversation.json (historique de votre conversation) si cela ne vous dérange pas.
